# BrowseWise

> Privacy-first screen-time and digital wellbeing tracking for Google Chrome.

**Status:** 🚧 In development. Not yet installable.

BrowseWise measures how much active time you spend on each website and shows it in a local analytics dashboard. Everything stays on your device: no accounts, no servers, no analytics.

## Planned features

- Active-tab screen-time tracking with idle and focus detection
- Daily, weekly, and monthly analytics
- Automatic website categories with manual overrides
- Daily goals and per-site limits with optional notifications
- Local history with CSV/JSON export and one-click data deletion

## A note on what "screen time" means

BrowseWise measures **active browsing time**: time the Chrome window is focused, the tab is in the foreground, and you are not idle. It does not measure attention or intent.
