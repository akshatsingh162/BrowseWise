BrowseWise bundles the following open-source software. Each is used under its licence, and attribution is given here because minified release builds strip licence comments from the code.

| Software                                         | Version      | Licence     | Used for                        |
| ------------------------------------------------ | ------------ | ----------- | ------------------------------- |
| [Chart.js](https://www.chartjs.org)              | 4.6.1        | MIT         | Analytics charts                |
| [@kurkle/color](https://github.com/kurkle/color) | 0.3.4        | MIT         | Colour handling inside Chart.js |
| [Lucide](https://lucide.dev)                     | 1.70.0       | ISC         | Interface icons                 |
| [Inter](https://github.com/rsms/inter)           | latin subset | SIL OFL 1.1 | Typeface (bundled font file)    |

Development tools (Vite, Vitest, ESLint, Prettier, jsdom) are used to build and test the extension and are not shipped to users.

The full licence texts are available in each package's repository. The Inter licence is included at `src/ui/fonts/LICENSE-Inter.txt`.
